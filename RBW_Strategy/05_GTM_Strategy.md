## 1. RBW 公司层面的 GTM 框架

### 1.1 GTM 三大原则

1. **Founder-led marketing** — 创始人本人就是 RBW 的最强营销资产，必须深度参与早期内容创作和社群互动。
2. **Built-in virality** — 三个产品都设计了天然分享触发点（结果截图、聚会场景、家长群口碑）。
3. **Zero-paid-spend until PMF** — 在 product-market fit 数据出现前（每个产品有明确的 retention 信号），不做大规模付费投流。

### 1.2 GTM Funnel（统一模型）

```
        Awareness
   (TikTok / 小红书 / IG / 抖音 / Reddit)
              ↓
        Curiosity
   (短视频 / 笔记 / 朋友推荐)
              ↓
         First Use
   (扫码 / 链接 / 应用打开)
              ↓
         Magic Moment
   (产品在 30 秒内让用户"哇"一下)
              ↓
       Repeat & Share
   (回访 + 朋友传播)
              ↓
         Convert
   (订阅 / 付费报告 / 主题包)
              ↓
         Retain & Refer
   (高频回访 + 推荐返利)
```

每个产品都按这套漏斗设计自己的关键指标（详见 `08_Roadmap_KPI.md`）。

### 1.3 全球 + 中文双线策略

| 市场 | 优先产品 | 主渠道 | 关键内容形态 |
|---|---|---|---|
| 中国大陆 | MagicCube + Vibe Party | 小红书 / 抖音 / 微信群 | 短视频 / 图文笔记 / 群推荐 |
| 全球华人（北美、东南亚） | Vibe Party + RBW Meta | 留学生群 / 小红书 / IG | 中英双语短视频 |
| 英语市场 | RBW Meta | TikTok / IG Reels / Reddit | 占星短视频 / 用户截图 |

## 2. RBW Meta（Spiritual AI）GTM

### 2.1 第一目标市场

- 优先 1：**英语 TikTok / IG Reels 用户**（Gen Z 女性为主，对 astrology / tarot / self-discovery 内容高消费）
- 优先 2：**小红书中文用户**（同人群中文版本）

### 2.2 第一批 100 名核心用户

- 从创始人个人社交网络出发，找 20–30 个对玄学 / 灵性内容感兴趣的种子用户。
- Reddit r/astrology, r/tarot 友善地分享一个"试用链接"，**禁止硬广**。
- 个人 IG / TikTok 账号每日发 1–3 条短视频，引导关注 + 试用。

### 2.3 冷启动方法

1. **创始人账号矩阵**：英文 TikTok + 英文 IG + 小红书 + Twitter/X 同步运营。
2. **内容范式**：
   - "我让 AI 给我读塔罗：第 X 天" 系列
   - "Co-Star 没说的事" 系列
   - "Birth chart but make it actually useful"
3. **可分享性优先**：每个产品 output 都设计成竖屏截图，自带 watermark。
4. **Waitlist 营造稀缺**：先发布 waitlist 页面，邀请制开放，制造排队感。

### 2.4 KOL / KOC 合作

- **微影响力（1k–50k 粉丝）的 astrology / tarot creator** 是最佳合作对象：互惠（免费 Pro 账号 + 内容素材）。
- 避免大 KOL（贵且效果差），优先 50 个 micro。
- 提供"creator dashboard"，让 KOL 可以分享专属链接看自己引流贡献。

### 2.5 社群运营

- 创建一个 **RBW Insiders** 私域（Discord 英文 + 微信群 / 小红书群中文）。
- 每周一次 "Reading Drop"：限时主题报告免费试用。
- 每月一次 "Vibe Check" 直播 / 语音房，创始人露脸 + 用户互动。

### 2.6 裂变机制

- **结果分享卡片**：每次报告生成完毕，自动生成可分享的卡片图。
- **邀请返利**：邀请 3 位朋友解锁 1 份高级报告。
- **每日打卡**：连续 7 天打卡解锁专属内容。

### 2.7 国际化步骤

1. **EN-first 全球版**（USD 计价）
2. **中文版（简繁双轨）**
3. **日韩版本**（高客单价市场）
4. **西班牙语 / 葡萄牙语**（拉美高 ARPU astrology 市场）

### 2.8 数据指标

- 注册 → 首次完整体验转化率 > 60%
- D7 留存 > 25%
- 免费 → 付费 > 3%
- 月度内容分享数 / MAU > 30%

## 3. MagicCube GTM

### 3.1 第一目标市场

- **中国一二线城市 6–14 岁儿童家长**（妈妈为主决策人）。
- 海外可以放到 Phase 2（重点是 speed cubing 社群）。

### 3.2 第一批 100 名付费家长

- 创始人 / 团队个人朋友圈 + 妈妈群定向邀请。
- 与 5–10 个母婴 / 育儿小红书账号合作（赠送年度会员换内容）。
- 抖音 / 视频号发布"3 分钟教孩子复原一面"短视频，引导关注。

### 3.3 冷启动方法

1. **"看孩子学魔方"系列短视频**（妈妈视角，真实进步过程）。
2. **零基础挑战赛**：免费 7 天挑战 → 完成的家长可优惠订阅。
3. **小红书种草笔记**：与 30 个母婴 KOC 合作铺笔记。
4. **学校试点**：3–5 所学校做免费试点，换取家长群口碑。

### 3.4 内容营销策略

- **教学短视频**：每条 30–60 秒，解决一个具体问题。
- **家长成长日记**：用户成长故事改编。
- **产品对比内容**：MagicCube vs 线下课，VS 视频教程。
- **节日活动包**：寒暑假训练营、新年挑战赛。

### 3.5 渠道策略

| 渠道 | 重点 | 期望转化率 |
|---|---|---|
| 小红书 | KOC 铺量 + 妈妈群口碑 | 笔记 → 试用 5% *(假设)* |
| 抖音 / 视频号 | 教学短视频 + 直播 | 视频 → 试用 1–3% *(假设)* |
| 微信群 / 朋友圈 | 家长口碑 | 邀请 → 注册 30% *(假设)* |
| 学校 / 课后服务 | B2B2C | 触达 → 试用 20% *(假设)* |
| 电商联名 | 实体魔方厂商 | 礼盒附码 | 

### 3.6 KOL / KOC 策略

- 主打 KOC（小博主、班级群家长意见领袖）。
- 与 30–50 位 KOC 建立"种子家长"关系，提供免费会员换真实体验内容。
- 后期请 2–3 位中等 KOL 做"行业认证"型背书。

### 3.7 社群运营

- **班级群微信运营**：以"魔方学习训练营"名义建群，免费内容运营换转化。
- **家长成长群**：付费用户专属群，每周训练打卡 + 教练在线答疑。
- **儿童成就墙**：孩子的成绩展示页（家长发朋友圈触发口碑）。

### 3.8 裂变机制

- **拼团**：3 人成团 79 元/年。
- **邀请送月卡**：邀请 1 位朋友送 1 个月。
- **挑战赛排行榜**：班级 / 学校 / 全国排行榜。

### 3.9 数据指标

- 试用 → 付费转化率 > 8% *(假设)*
- 续费率（年）> 45%
- 单课成本 < 30 元 CAC

## 4. Vibe Party GTM

### 4.1 第一目标市场

- **中国一二线城市 18–30 岁聚会发起人**
- **海外华人留学生群体**（北美、英国、澳洲、东南亚）

### 4.2 第一批 100 个种子聚会

- 创始人 + 朋友亲自参加 / 组织 20–30 场聚会，现场使用产品。
- 找 50 位"组局王"朋友（被推荐做组局者），免费给他们 Pro Pass 换聚会现场反馈。

### 4.3 冷启动方法

1. **真实聚会场景视频**（带朋友玩、拍下笑场反应、发小红书 / 抖音）。
2. **留学生学生会合作**：万圣节 / 圣诞 / 中秋活动作为官方破冰工具。
3. **KTV / 酒吧种子合作**：3–5 家年轻人酒吧 / 量贩 KTV 免费提供活动支持。
4. **生日 / 暧昧局主题包**作为预付费产品测试 PMF。

### 4.4 内容营销

- 主推"现场效果"短视频：朋友笑场、被惩罚的尴尬瞬间、暧昧 moment。
- 主题包发布事件化：每周一个新主题包，制造期待。
- 与生活方式 KOL 合作"组局体验"内容。

### 4.5 社交媒体策略

| 渠道 | 内容形态 | 频率 |
|---|---|---|
| 抖音 / 视频号 | 现场反应剪辑 | 每日 1–2 条 |
| 小红书 | 主题包推荐笔记 + 组局指南 | 每周 3–5 条 |
| IG / TikTok（海外华人） | 留学生派对 vlog | 每周 2 条 |
| 微信朋友圈广告 | 节日活动包推广 | 节日前一周 |
| 微信群（活动 / 学生会） | 直接邀请群主试用 | 每月 BD 30+ 群 |

### 4.6 KOL / KOC 策略

- 找 50 位"留学生组局王"做 ambassadors，免费 Pro Pass + 主题包内测。
- 找 20 位生活方式 / 派对类 KOL 做内容植入。
- 找 5–10 位 HR / 团建组织者做 B2B 入口。

### 4.7 线下合作

- **KTV 合作**：在大厅二维码扫码"暖场神器"。
- **量贩酒吧**：提供品牌联名主题包（"XX 酒吧专属游戏"）。
- **活动公司**：成为他们的标配工具，分润模式。
- **学生会 / 留学生组织**：节日活动赞助。

### 4.8 裂变机制

- 每场聚会平均拉新 3–5 人（天然病毒）。
- **聚会回顾报告**：游戏结束后生成"今晚最大赢家 / 最尴尬瞬间"卡片，自带分享按钮。
- 邀请 5 位朋友解锁专属主题包。

### 4.9 国际化路径

1. **中文 v1**（中国 + 全球华人留学生）
2. **英文 v2**（北美派对场景）
3. **韩文 / 日文 v3**（东亚留学生 + 本地年轻人）
4. **节日定制版**（万圣节、新年、情人节多语言）

### 4.10 数据指标

- 单场聚会平均拉新 K 值 > 1.2
- D7 留存 > 20%（聚会是低频高黏产品，留存定义需调整）
- 主题包付费转化率 > 2%
- 分享率（聚会后生成卡片分享） > 25%

## 5. 公司级别的内容工厂（Founder 一人可执行）

### 5.1 每周内容发布节奏（假设创始人单兵）

| 频道 | 周一 | 周三 | 周五 | 周日 |
|---|---|---|---|---|
| 个人 TikTok / IG | RBW Meta 内容 | 创始人日常（建立人设） | Vibe Party 现场片段 | RBW Meta 用户故事 |
| 个人小红书 | MagicCube 家长见证 | RBW Meta 测试 | Vibe Party 主题预告 | 长文：RBW 公司故事 |
| Twitter/X | Build in public 进度 | 关于 vibe coding 的思考 | Product hunt 风格更新 | 一周回顾 |

### 5.2 内容资产复用原则

- 1 条长内容（YouTube 长视频 / 长文）→ 拆 10 条短内容。
- 用户截图 / 反馈 → 二次创作素材。
- 三个产品互推（不强行，但顺势）。

## 6. 启动顺序建议（GTM 时间表）

| 时间 | RBW Meta | MagicCube | Vibe Party |
|---|---|---|---|
| Month 0–1 | Waitlist + 创始人内容矩阵搭建 | MVP 开发 | 原型设计 + 内容池开始 |

| Month 6–12 | 国际化 + 订阅启动 | B2B 学校试点 + 续费验证 | B2B 活动版启动 + 国际化 |

## 7. GTM 风险与对策

| 风险 | 对策 |
|---|---|
| 创始人内容产能瓶颈 | 至少招 1 位内容协作者（早期可外包） |
| 多产品营销资源分散 | 每周仅 1 个产品作为"主推"，其他维持基础节奏 |
| 海外 GTM 文化误判 | 早期不投流，先听用户、调内容 |
| 小红书 / 抖音算法不稳 | 多平台分散 + 自有私域同步沉淀 |
| 付费转化低于假设 | 不强推付费，先做留存；retention > 25% 再谈变现 |

## 8. 三个产品的 GTM 优先级（资源 80/20）

| 阶段 | 80% 资源主推 | 20% 资源维持 |
|---|---|---|
| Month 0–3 | **MagicCube**（最快现金流） | RBW Meta waitlist + Vibe Party 原型 |
| Month 3–6 | **RBW Meta**（声量 + 高毛利） | MagicCube 运营 + Vibe Party Beta |
| Month 6–12 | **Vibe Party**（病毒 + B2B） | RBW Meta 国际化 + MagicCube 续费 |

> 这个轮换节奏对外可以讲成"**Quarterly Spotlight**"——每个季度 RBW 集中讲一个产品的故事，避免任何时候都讲三件事让人困惑。
