## A · Spiritual AI / 玄学 AI / Self-Discovery AI 市场

### A.1 全球趋势（PESTEL 简版）

| 维度 | 趋势 |
|---|---|
| **Political** | 各国对 AI 内容监管收紧（EU AI Act、中国生成式 AI 管理办法），但娱乐性 AI 内容仍属低风险类别。 |
| **Economic** | 后疫情时代消费下降，但"低价情绪消费"反而增长（小红书"开运"、亚马逊水晶销量、Co-Star 订阅）。 |
| **Social** | Gen Z & Millennial 对传统宗教参与度下降，但对"灵性 / spirituality / wellness"兴趣上升——这是一个**世俗化、去宗教化、个人化**的灵性市场。 |
| **Technological** | LLM 让"每个人有一个塔罗师/星座师"的体验成本接近于零，是品类代差机会。 |
| **Environmental** | 不显著相关。 |
| **Legal** | 美国 FTC 关注"AI 心理咨询"边界；需明确娱乐定位 disclaimer。 |

### A.2 市场规模（假设 + 行业常识）

- 全球 wellness 市场约 **USD 1.8T**（McKinsey 2024，*行业常识*）。其中 *mindfulness + spirituality* 子类是增长最快的几个 segment 之一。
- 全球 astrology app 市场约 **USD 12–15B** 量级 *(行业常识，需验证)*，代表玩家 Co-Star、The Pattern、Sanctuary、Nebula、AstroTalk（印度）。
- **TAM** *(假设)*：全球愿意为"self-discovery / spiritual / divination AI"内容付费的用户约 1.5–2 亿。
- **SAM** *(假设)*：英语 + 华语市场的 18–40 岁女性为主，约 4000–6000 万。
- **SOM**（3 年内）*(假设)*：50–100 万 MAU，付费率 3–8%，ARPU 月度 USD 4–12 = USD 1.5–8M ARR 量级。

### A.3 用户心理需求（Jobs To Be Done）

用户雇佣这类产品来完成的"jobs"：

1. **JTBD-1**: "我今天心情不好，我需要一个不评判我的对话伙伴。"
2. **JTBD-2**: "我想知道我是什么样的人 / 适合什么样的伴侣 / 适合什么样的工作。"
3. **JTBD-3**: "我想要一种小小的仪式感，让今天有点不一样。"
4. **JTBD-4**: "我对未来焦虑，我需要一种'有人在看着我'的安慰。"
5. **JTBD-5**: "我想要可以发到 Instagram / 小红书的、好看的、有故事性的内容。"

**关键洞察**：用户买的**不是预测**，是**情绪陪伴 + 自我反思 + 社交货币**。这正是合规和差异化的根基。

### A.4 用户画像（Personas）

- **Luna，26 岁，纽约设计师**：每天早上看 Co-Star，晚上做 tarot。愿意为"我的星盘报告 PDF"付 USD 19。
- **小雨，22 岁，北京研究生**：小红书重度用户，喜欢 MBTI、紫微斗数、星座；愿意付 18 元买"年度运势报告"。
- **Sarah，34 岁，伦敦市场经理**：在大公司工作，订阅冥想 + 占星 app 已成习惯，月付 USD 9。
- **Priya，29 岁，孟买**：AstroTalk 重度用户，相信玄学也愿意为单次咨询付 USD 2–5。

### A.5 使用场景

- 早晨开机第一件事（每日运势 / 卡片）
- 晚上睡前自我反思（日记 + 解读）
- 重大决策前（换工作、分手、搬家）
- 情绪低谷时（情感陪伴）
- 社交分享（截图发朋友圈 / IG Story）

### A.6 竞品类型（详见 `06_Competitive_Analysis.md`）

- **西方代表**：Co-Star、The Pattern、Sanctuary、Nebula、Stellar、Chani。
- **东方代表**：测测星座、第一星座、紫微斗数 / 八字 类微信小程序、Soulful AI（韩）、AstroTalk（印）。
- **AI Companion 邻接**：Replika、Character.ai、Pi。

### A.7 变现方式

- **订阅制**（USD 4.99–9.99/月，行业主流）
- **付费报告**（一次性付费 USD 9.99–29.99，毛利最高）
- **AI Chat 增值**（高级人格、定制声音、长对话记忆）
- **每日推送 + 推送广告**（早期不推荐）
- **联名 / 周边**（水晶、卡牌、香薰）

### A.8 增长渠道

- TikTok / Instagram Reels 短视频（高 viral 系数）
- 小红书图文笔记（华人市场最强渠道）
- YouTube Shorts 解读视频
- 占星 / 灵性领域 KOL 合作
- Reddit r/astrology, r/tarot 社群（注意社群文化）
- 搜索 SEO："my birth chart"、"is he my soulmate" 类长尾词

### A.9 风险与合规边界

- ❌ 不承诺真实未来预测
- ❌ 不做心理疾病诊断、不替代心理医生
- ❌ 不做法律 / 金融 / 医疗建议
- ❌ 不利用用户脆弱性进行情感胁迫付费
- ✅ 所有内容定位为 **"for entertainment and reflection"**
- ✅ 关键时刻提供"如果你感到痛苦，请联系专业帮助"的 disclaimer
- ✅ 跨文化敏感性审查（伊斯兰、基督教保守地区可能拒绝相关内容）

### A.10 RBW 的差异化机会

| 维度 | 现有玩家短板 | RBW 机会 |
|---|---|---|
| 视觉审美 | Co-Star 极简但冷；多数中文产品丑 | **东方审美 + 国际化设计**双线品牌 |
| 文化融合 | 西方产品不懂八字、紫微、易经；东方产品不懂塔罗、行星 | **跨文化玄学**是巨大蓝海 |
| AI 深度 | 多数仅模板化文字 | **真正的 LLM 对话陪伴**体验 |
| 多产品组合 | 单品类公司多 | **三个产品组合**互相导流 |

## B · MagicCube / AI 智能魔方学习市场

### B.1 市场需求

- **儿童素质教育**在中国是政策鼓励的方向（双减后家长把预算转移到非应试技能）。
- **脑力训练 / STEAM 教育**在全球都是稳定增长品类。
- 魔方是一个**符号性极强**的认知训练入口：家长一听就知道"是好东西"。
- 海外 **Speed cubing** 社群活跃，有 WCA（World Cube Association）等正式赛事体系。

### B.2 用户画像（Personas）

- **小宇，9 岁，上海**：被妈妈报名魔方课，每周 1 次 98 元/小时，3 个月学完一面就停了。
- **王妈妈，37 岁，杭州**：愿意为孩子兴趣付费，但讨厌线下接送 + 不知道孩子有没有进步。
- **Alex，14 岁，多伦多**：自己想速拧，看 YouTube 教程但太碎片化。
- **大彬，28 岁，深圳**：成人兴趣 / 解压用户，月活但不愿意付高价。

### B.3 付费意愿

- 中国家长在儿童兴趣班的年支出常见 **3000–10000 元**（*行业常识*）。
- 99 元/年订阅相对线下课（98 元/单次）只占 **1/30 的价格**，几乎是无脑决策门槛。
- 关键问题：**让家长理解"这是一个完整训练系统"，而不是"99 元的小 App"**。

### B.4 线下课程的痛点

1. 贵（98 元/单次 × 一年 40 次 ≈ 4000 元）
2. 接送 / 守候成本（家长 2 小时机会成本）
3. 反馈滞后（家长不知道孩子学到哪了）
4. 教学方式落后（看公式纸抄）
5. 失去兴趣后没有挽回机制（不会做个性化提醒）

### B.5 在线教学产品的机会

| 痛点 | MagicCube 的对应解法 |
|---|---|
| 公式难记 | AI 把公式拆成"动画 + 节奏 + 口诀"，按掌握度推送 |
| 没有反馈 | 计时 / 步数 / 错误模式可视化训练日志 |
| 家长没法陪 | 家长端报告，每周一封"孩子本周成长" |
| 进度卡住 | AI 检测停滞 → 推送针对性挑战 |
| 兴趣下降 | 成就系统 / 同龄人排行榜 / 节日挑战赛 |

### B.6 AI / 数据追踪 / 训练系统的价值

- **个性化学习路径**（同样是初学者，进度不同）
- **错误模式识别**（"你在 F2L 第 3 步总是失误"）
- **训练习惯养成**（学习曲线可视化）
- **家长安心感**（这是 99 元 vs 4000 元的真正护城河）
- **未来横向扩展**（同一引擎可以训练记忆、口算、围棋等）

### B.7 定价 99 元/年的合理性

✅ **合理**，原因：
- 心理价位"100 元以下"是订阅决策的天然门槛（小红书、B 站会员、得到等都印证）。
- 单价低 → 高转化率 → 病毒系数高（家长群、班级群口碑传播）。
- 99 元 / 年 = 月均 8.3 元，几乎不可拒绝。
- 给后续高价 SKU（家庭版 199、训练营 599、实体礼盒 299）留升级空间。

**风险**：低价 → 单用户经济模型脆弱，需要：
- 极低 CAC（< 30 元）→ 依赖口碑而非投流
- 高续费率（> 50%）→ 依赖产品价值感
- 后续高 ARPU SKU 拉升 LTV

### B.8 获客渠道

| 渠道 | 适配度 |
|---|---|
| 小红书（家长账号 / 育儿账号） | ⭐⭐⭐⭐⭐ |
| 抖音 / 视频号（魔方教学短视频） | ⭐⭐⭐⭐⭐ |
| 微信家长群口碑 | ⭐⭐⭐⭐ |
| 公立学校 / 课后服务合作 | ⭐⭐⭐⭐ |
| 京东 / 淘宝魔方实体商品引流 | ⭐⭐⭐ |
| YouTube / TikTok（海外） | ⭐⭐⭐ |

### B.9 与教育机构 / 学校 / 亲子平台合作可能

- **课后服务包**：与学校合作提供素质教育包，按生均收费。
- **机构白标**：少儿编程 / STEAM 机构白标 MagicCube 作为附加课程。
- **实体魔方品牌联名**：与魔方厂商（GAN、MoYu）做礼盒。
- **亲子社群导流**：宝宝树、年糕妈妈、丁香妈妈等。

## C · Vibe Party Games / Web 派对互动市场

### C.1 目标用户

- **18–32 岁，城市年轻人**（中国一二线 + 全球华人 + 留学生）
- **聚会发起者人格**：朋友圈里"组局王"，乐于尝鲜，乐于分享。
- **次级用户**：HR / 团建组织者、活动主持人、KTV/酒吧运营。

### C.2 高频场景

| 场景 | 频率 | 痛点 |
|---|---|---|
| 朋友聚餐 / 家庭聚会 | 每月 2–4 次 | 吃完不知道干嘛 |
| 生日派对 | 每年 5–10 次 | 找不到合适的破冰活动 |
| KTV / 酒吧 | 每月 1–3 次 | 唱歌之外的间歇尴尬 |
| 留学生聚会 | 每月 2–4 次 | 需要中文 / 多文化破冰 |
| 公司团建 | 每季 1 次 | HR 找不到不尴尬的破冰 |
| 旅行途中 | 每年 2–5 次 | 长途车 / 候机时打发时间 |
| 暧昧约会 | 不定 | 升温话题 |

### C.3 用户痛点

1. 没人愿意带桌游 / 卡牌（重、贵、规则难讲）
2. 现有 App（如某些海外 party app）UI 廉价、内容老旧、不够中文化
3. 喝酒游戏让人不适、有社交压力
4. 主持人不在时聚会冷场
5. 想发朋友圈但游戏过程"不好看"

### C.4 替代品 & 竞品（详见 `06_Competitive_Analysis.md`）

- 实体桌游 / 卡牌（黑桃、UNO、谁是卧底卡牌）
- 海外类似 App（不点名）
- 微信小程序里的"派对小游戏"集合
- 抖音 / 小红书的"派对游戏"短视频内容

### C.5 为什么 Web-based 是优势

| 优势 | 说明 |
|---|---|
| **零安装** | 扫码即玩，不强迫朋友下载 App |
| **跨平台** | iOS / Android / 桌面通用 |
| **更新即时** | 不需要审核，可周更新内容 |
| **病毒系数高** | 一个 URL 就是一次传播 |
| **数据透明** | Web 端 analytics 完整 |
| **国际化简单** | 一个域名服务全球 |

### C.6 为什么手机优先

- 聚会场景手机是默认终端
- "一群人围一台手机"是天然的社交结构（每个人都在看同一块屏）
- 不打断喝酒、吃饭的节奏

### C.7 中文市场启动

- **种子用户**：留学生群（北美、英国、澳洲）+ 一线城市年轻人
- **冷启动场景**：生日局、留学生中秋 / 春节聚会、KTV 暖场
- **内容首批**：100 条原创破冰话题 + 30 个原创小挑战 + 5 套主题包（朋友局 / 闺蜜局 / 公司团建 / 暧昧局 / 留学生局）

### C.8 国际化路径

1. **中文中文 v1**：先在华人聚会场景跑通产品。
2. **多语版 v2**：英语 / 韩语 / 日语，对应留学生 + 东亚年轻人。
3. **本地化主题包**：圣诞 / 万圣节 / 新年 / 情人节。
4. **B2B 全球版**：跨国公司团建、英语主持人版本。

### C.9 商业模式

| 模式 | 描述 | 优先级 |
|---|---|---|
| Freemium | 基础免费玩 | ⭐⭐⭐⭐⭐ |
| **Pro Party Pass**（一次性 / 月订阅） | 解锁高级主题包、自定义内容、无广告 | ⭐⭐⭐⭐⭐ |
| 主题包付费（节日 / 暧昧局 / 留学生） | 一次性付费 9–29 元/包 | ⭐⭐⭐⭐ |
| **B2B 活动版** | KTV / 酒吧 / 团建定制 | ⭐⭐⭐⭐ |
| 品牌联名活动包 | 节日营销活动 | ⭐⭐⭐ |
| Drinking Mode（年龄确认后付费解锁） | 18+ 模式 | ⭐⭐⭐（合规优先） |

### C.10 安全边界 & 内容审核

- 默认无酒精（默认词"挑战 / 惩罚 / 扣分 / 表演"）
- Drinking Mode 必须显式年龄确认，且独立内容池
- 所有挑战都可跳过
- 禁止涉及：性骚扰、强迫接触、危险行为、违法行为、羞辱、歧视、未成年人不当内容
- 三级内容分级：**Light（家庭友好）/ Spicy（成人朋友）/ Drinking（18+）**
- 内容池由 RBW 原创，禁止抄袭现有桌游 / App / 卡牌的具体玩法、文案、视觉资产、角色、代码

## 跨市场战略洞察

1. **三个市场没有重叠的竞争对手** → RBW 不会与同一家公司在所有战线竞争。
2. **三个市场用户画像高度重合**（女性年轻人主导）→ 跨产品交叉营销可行。
3. **三个市场都缺少"国际化审美 + AI 深度 + 安全合规"**三者兼具的玩家 → 这是 RBW 的差异化窗口。
4. **三个市场都适合 vibe coding 的快速迭代**（轻量内容 + 强 prompt 设计 + 不需重资产）。
