## 2. RBW Meta（Spiritual AI）商业模式

### 2.1 收入模型

| 收入项 | 形式 | 价格假设 | 备注 |
|---|---|---|---|
| 订阅（核心） | Monthly / Annual | USD 6.99/月 或 USD 49.99/年 | 行业主流 |
| 付费报告 | 一次性 | USD 9.99–29.99 / 份 | 毛利最高，建议主推 |
| AI Companion 增值 | 月订阅升级 | +USD 4/月 | 长对话记忆、定制声音 |
| 联名 / 周边 | 一次性 | USD 19–49 | 长尾品牌附加 |
| 广告 | CPM | 极低（早期不推荐） | 仅在免费用户暴露 |

### 2.2 阶段性变现路径

| 阶段 | 变现重点 | 目标 |
|---|---|---|
| **MVP（0–3 月）** | 仅免费 + 1 个付费报告 SKU | 验证愿付意愿，目标 100 笔付费 |
| **6 月** | 加入订阅制 | MRR USD 3k |
| **12 月** | 订阅 + 报告 + Companion 三轨 | MRR USD 15–30k |
| **3 年** | 跨地区运营 + 联名 / 实体周边 | ARR USD 3–8M |

### 2.3 关键假设（需要数据验证）

- 免费 → 付费转化率：**3–6%** *(假设，对标 Co-Star / Nebula)*
- ARPU 月度：**USD 5–8** *(假设)*
- 6 个月留存：**30–45%** *(假设)*
- 单付费报告毛利率：**> 85%**（LLM API 成本极低）
- CAC（社媒有机为主）：**USD 1–3** *(假设)*；付费投流 **USD 5–15**
- LTV / CAC 目标：> 3x（健康标准）

### 2.4 12 个月情景模型 *(假设)*

| 情景 | MAU | 付费率 | ARPU/月 | MRR (Month 12) |
|---|---|---|---|---|
| 保守 | 30,000 | 3% | USD 5 | **USD 4,500** |
| 中性 | 80,000 | 4% | USD 6 | **USD 19,200** |
| 乐观 | 200,000 | 5% | USD 7 | **USD 70,000** |

## 3. MagicCube（AI Learning）商业模式

### 3.1 收入模型

| 收入项 | 形式 | 价格假设 |
|---|---|---|
| **个人版年订阅** | Annual | **99 元/年**（核心 SKU） |
| 家庭版 | Annual | 199 元/年（最多 3 孩子） |
| 训练营 / 挑战赛 | 一次性 | 99–299 元 |
| 实体魔方礼盒（联名） | 一次性 | 199–399 元 |
| 学校 / 机构 B2B 包 | 年度 / 生均 | 30–60 元/生/年 |
| 证书 / 成就实体周边 | 一次性 | 39–99 元 |

### 3.2 阶段性变现路径

| 阶段 | 变现重点 | 目标 |
|---|---|---|
| **MVP（0–3 月）** | 个人版 99 元/年 | 1000 付费用户（≈ 99k 元） |
| **6 月** | 加家庭版 + 训练营 | MRR-equivalent 50k 元/月 |
| **12 月** | 三 SKU 齐全 + 启动 B2B | ARR 300–600 万元 |
| **3 年** | 横向扩展到 3–5 种技能（速算 / 记忆等） | ARR 3000 万元 + |

### 3.3 关键假设

- 99 元/年订阅，预付现金流（VS 月订阅）→ 现金流模型极健康
- 续费率（年）：**45–60%** *(假设)*
- CAC（小红书 + 抖音口碑）：**< 30 元** *(假设)*；付费投流 **80–150 元**
- LTV（2 年视角）：**150 元** *(假设)*
- LTV / CAC 目标：> 3x
- 家庭版升级率：**15–25%** *(假设)*
- B2B 单校年合同：**5,000–30,000 元** *(假设)*

### 3.4 12 个月情景模型 *(假设)*

| 情景 | 付费用户数 | 平均 ARPU/年 | 年化收入 |
|---|---|---|---|
| 保守 | 3,000 | 110 元 | **33 万元** |
| 中性 | 10,000 | 130 元 | **130 万元** |
| 乐观 | 30,000 | 150 元 | **450 万元** |

### 3.5 关键增长杠杆

1. **家长群口碑**（最低 CAC）
2. **学校课后服务合作**（一次签约带来稳定 B2B2C 用户）
3. **实体魔方厂商联名**（流量互换）
4. **同龄人挑战赛**（自然分享）
5. **训练数据可视化报告**（家长发朋友圈触发口碑）

## 4. Vibe Party（Social Play）商业模式

### 4.1 收入模型

| 收入项 | 形式 | 价格假设 |
|---|---|---|
| 基础玩法 | 免费 | — |
| **Pro Party Pass** | 月订阅 / 年订阅 | 19 元/月 或 99 元/年 |
| 主题包（节日 / 暧昧 / 留学生 / 团建） | 一次性 | 9–29 元/包 |
| **B2B 活动版**（KTV / 酒吧 / 团建） | 年度 SaaS | 500–5,000 元/场地/年 |
| 品牌联名活动包 | 项目制 | 5,000–50,000 元/项目 |
| Drinking Mode（18+，独立内容池） | 一次性付费解锁 | 19 元 |

### 4.2 阶段性变现路径

| 阶段 | 变现重点 | 目标 |
|---|---|---|
| **MVP（0–3 月）** | 完全免费，跑病毒 | DAU 1k+，分享率 > 25% |
| **6 月** | 上线主题包 + Pro Pass | 月流水 3–10 万元 |
| **12 月** | 启动 B2B 活动版 | ARR 100–300 万元 |
| **3 年** | 国际化版本 + 品牌联名 + 全球 KTV 渠道 | ARR 千万级 |

### 4.3 关键假设

- 免费 → 付费转化率：**1–3%** *(假设)*（社交产品天然较低）
- 病毒系数 K：目标 > 1.2 *(假设)*
- 单聚会平均使用时长：**30–60 分钟** *(假设)*
- 单聚会拉新数：**3–5 人** *(假设)*
- B2B 单签约毛利率：> 70%

### 4.4 12 个月情景模型 *(假设)*

| 情景 | MAU | 付费率 | ARPU/年 | B2B 客户数 | 年化收入 |
|---|---|---|---|---|---|
| 保守 | 50,000 | 1% | 50 元 | 5 | **27.5 万元** |
| 中性 | 200,000 | 2% | 70 元 | 30 | **300 万元** |
| 乐观 | 800,000 | 3% | 90 元 | 100 | **2,310 万元** |

### 4.5 商业模式护城河

- **内容库的持续更新**（每周更新 → 用户回访理由）
- **品牌资产**（"派对就用 Vibe Party" 心智占位）
- **B2B 场地网络**（一旦签约 KTV / 酒吧，迁移成本高）
- **数据洞察**（哪些主题包在哪些场景最火 → 内容研发壁垒）

## 5. 三产品组合的财务总览 *(12 个月，中性情景，假设)*

| 产品 | 中性 ARR (Month 12) | 毛利率 | 主要变现形态 |
|---|---|---|---|
| RBW Meta | ≈ USD 230k *(≈ 165 万元)* | > 80% | 订阅 + 付费报告 |
| MagicCube | ≈ 130 万元 | > 75% | 年订阅 |
| Vibe Party | ≈ 300 万元（含 B2B） | > 70% | Pro + 主题包 + B2B |
| **合计** | **≈ 595 万元 / ≈ USD 830k** | **平均 ~75%** | **三轨并行** |

> 这是一个"小而美"的 ARR 水平，但**关键不是绝对值，而是三种商业模式的同时验证**。
> 对 Pre-seed / Seed 投资人来说，"我们在三个不同的商业引擎上各跑通了一段"比"一个产品 ARR 500 万"更有故事性，因为它证明了 RBW 的 **studio 模式**有效。

## 6. 单位经济模型（Unit Economics 框架）

每个产品都应该满足：

```
LTV / CAC ≥ 3
Gross Margin ≥ 70%
Payback Period ≤ 12 months
Net Revenue Retention (订阅产品) ≥ 90%
```

**MagicCube** 因为预付年订阅，payback period 可压缩到 < 3 个月，**这是 RBW 现金流的真正基石**。

## 8. 商业模式风险（详见 `07_Risk_Compliance.md`）

| 风险 | 缓解 |
|---|---|
| LLM API 成本失控 | 缓存 + 本地小模型 + 限流 |
| 低价 SKU 毛利稀释 | 高 ARPU SKU 拉升（家庭版、Companion、B2B） |
| 付费转化率假设过高 | MVP 阶段每周复盘，假设 → 真实数据替换 |
| 跨境收款合规（玄学产品） | Stripe / Paddle 等合规渠道 |
| Vibe Party B2B 销售周期长 | 先做 SMB（小酒吧、活动公司），不做大客户 |

## 9. 投资人感兴趣的财务点

1. **MagicCube 预付年订阅** = 极佳现金流模型（投资人爱）。
2. **RBW Meta 高毛利 + 全球可扩展** = 故事性最强。
3. **Vibe Party 病毒系数** = 估值倍数最高。
4. **三产品共享底层 LLM 框架** = 边际成本递减。
5. **创始人 vibe coding** = 极低团队规模即可运转，烧钱率低。
